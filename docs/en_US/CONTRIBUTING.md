## `ShaderPackPatcher`

The abstract logic in `ShaderPackPatcher` isn't very good because this project hasn't supported shaders other than *Bliss* yet, so it's currently unclear what needs to be abstracted.  
If support for a second shader is added, `ShaderPackPatcher` may need to be modified.
