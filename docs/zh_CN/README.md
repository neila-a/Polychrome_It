# 多彩化它！

[English](/docs/en_US/README.md) | 大陆简体中文

让您的 Minecraft 更加多彩。  
支持全 RGB 范围。

## Mod 支持

- *遥远的地平线*：已支持。
- *Xaero 的地图*：尚未支持。
- *旅行地图*：无需支持。颜色本来就可以被正确显示。

## 使用

### 非基于物理的渲染

1. 在*WorldMachine*中导出*高度图*和*位图*。
1. 在*WorldPainter*中导入*高度图*。
    1. 用`polychrome_it:image_pixel_block`覆盖地面。
1. 将*位图*放在`.minecraft/config/polychrome_it_image`。
